# 接手指南

本文记录 CodexDeck 网关与网页当前的实现和继续开发入口。先以磁盘上的代码与实际运行状态为准，再参考历史验证记录。

## 当前运行方式

- 在项目根目录执行下文命令，即本文档所在 `Docs/` 的上一级。
- Codex Desktop 需以本机 CDP 启动，默认端口为 `127.0.0.1:49397`。使用 `./scripts/start-desktop-cdp.ps1 -ProbeOnly` 检查。
- 网关入口是 `npm start`（`src/server.mjs`），默认监听 `127.0.0.1:8787`。`GET /api/health` 的 `connected: true` 才说明桥接到正在运行的 Desktop。
- 手机访问需要另设私网监听地址与强访问令牌；本机 CDP 始终只对本机开放。具体环境变量见根目录 [README](../README.md)。

## 同态链路与代码位置

网页 `public/index.html` 加载 `public/js/app.js`。HTTP API 在 `src/api.mjs`，经 `src/desktop-bridge.mjs` 的 CDP `Runtime.evaluate` 进入 Desktop 主页面，再用 Desktop 自有 `electronBridge` 请求同一个 app-server。网关不会启动第二个 Codex CLI 会话。

| 功能 | 主要文件 |
| --- | --- |
| HTTP 启动、固定静态资源、鉴权与参数校验 | `src/server.mjs`、`src/http.mjs` |
| 聊天、项目、模型、未读、目录 API | `src/api.mjs`、`src/models.mjs`、`src/directories.mjs` |
| Desktop CDP、项目服务、未读状态 | `src/desktop-bridge.mjs` |
| 审批中继、JSONL 上下文用量 | `src/approvals.mjs`、`src/usage.mjs` |
| 同步／异步提问与回答面板 | `src/questions.mjs`、`public/js/questions.js`、`public/css/questions.css` |
| 长回合过程分页、活动详情延迟生成 | `src/history.mjs`、`public/js/conversation.js`、`public/js/activity.js` |
| 本地图片签名读取、Markdown 与工具图片渲染 | `src/images.mjs`、`public/js/images.js` |
| 网页共享状态与请求 | `public/js/core.js` |
| 侧边栏、未读点、草稿与选择聊天 | `public/js/sidebar.js` |
| 回合渲染、发送/停止、模型滑块、目录窗口 | `public/js/conversation.js`、`public/js/app.js`、`public/js/settings.js`、`public/js/project-dialog.js` |
| 样式 | `public/style.css` 为入口；实际规则按基础、侧栏、对话、输入区、弹窗、响应式拆在 `public/css/` |

`desktop/` 是另一套 Electron GUI 源码，具有独立的 `desktop:build`、`desktop:test` 脚本；它与上述网页网关共用同一项目目录。继续修改它时应单独读取其源文件和测试，不能用网页验证结果代替 Desktop GUI 验证。

## 验证顺序

1. `npm test`：检查网关和网页模块语法，以及模型/思考等级参数校验。
2. 确认 Desktop CDP 已运行，执行 `npm run test:live`：只读检查静态资源和 Desktop 同态 API。
3. 写操作只在临时聊天中验证。`tests/test-live-approval.mjs <临时聊天 ID>` 会运行无副作用 `Get-Date` 审批测试，并保留聊天原有审批设置；不要对正式聊天运行。
4. 执行 `npm run test:ui`：在独立 Electron 窗口检查模型菜单与思考滑块、上下文提示、目录浏览器、三段折叠标题、发送/停止按钮及 390px 窄屏布局。截图保存在本地 `Docs/截图/`。
5. 修改提问、恢复同步或停止反馈时，分别执行 `npm run test:questions:ui`、`npm run test:sync:ui`；App 外壳的布局与恢复通知另运行 `node mobile-hbuilder/tests/webview-layout.mjs`。
6. 修改长回合分页和工具输出时，运行 `node tests/history.mjs`、`node tests/usage.mjs`、`npm run test:history:ui`、`npm run test:activity:ui`，并用 `test:sync:ui` 核对已加载旧过程的保留、重试及切换隔离。`test:history:ui` 还覆盖摘要先显示、提问连续跳转、自动分页、游标衔接和 390px 布局。
7. 修改图片时运行 `node tests/images.mjs` 和 `npm run test:images:ui`，覆盖签名及令牌、FRP 同源请求、工具图片延迟显示、加载失败、异步高度变化后的阅读位置和手机布局。

## 已知边界

- Desktop 的 CDP 页面、内部项目服务和 read-state 服务不是公开稳定接口；Desktop 升级后须重新做在线验证。
- `model/list` 返回的是 Desktop 模型目录，当前配置的 API 代理可能不支持其中部分模型；实测 `gpt-5.6-luna` 的回合被上游拒绝，`gpt-6-sol / high` 成功。网页会显示失败原因。
- 项目聊天按精确工作目录查询；子目录创建的旧聊天仍可能只出现在“最近”。
- 网页通过轮询更新状态；支持命令审批及同步／异步提问，附件、其他审批和 token 级流式展示尚未实现。
- 真机手机私网/VPN 连通性与 TLS 仍需另行验证；Electron 的 390px 布局检查不能代替真机触摸和网络验证。
